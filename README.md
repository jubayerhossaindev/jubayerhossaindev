## About

I build software with a focus on **developer experience, performance, and maintainability**. My work spans developer tooling, backend applications, and experiments with systems programming.

I enjoy taking an idea from a working prototype to a well-documented, tested, and maintainable project.

- **Developer tooling:** CLI utilities, formatters, and language-related tools.
- **Backend engineering:** Node.js applications, APIs, and data-driven systems.
- **Systems programming:** Exploring Rust for native and performance-sensitive software.

## Selected work

### [ESLint Formatter Crisp](https://github.com/jubayerhossaindev/eslint-formatter-crisp)

A Rust-powered ESLint formatter for Node.js, connected through N-API. The project provides readable terminal reports and JSON/SARIF output for different workflows.

[Repository](https://github.com/jubayerhossaindev/eslint-formatter-crisp) · [npm package](https://www.npmjs.com/package/eslint-formatter-crisp)

### [fresh-normalize](https://github.com/jubayerhossaindev/fresh-normalize-beta)

An early-stage CSS normalization project exploring accessible defaults, design tokens, and native dark-mode support.

[Repository](https://github.com/jubayerhossaindev/fresh-normalize-beta)
